Start Button Glow

リングは r=90px、線幅 6px（外周 r=93px）。 グローは radial-gradient 一枚、circle closest-side。 リップルはグローのピークに合わせて発火します。

Inner edge 82 px
Radius where the glow starts rising from zero.
Peak 91 px
Radius of maximum brightness. Ring outer edge is 93px.
Outer edge 127 px
Radius where the glow fades to zero. Div's half-extent.
Peak alpha 1.00
Colour #ffffff
Presets
Breath duration 5.0 s
Breath floor 0.00
Opacity at the dim end of the breath. 1.00 = no breath.
Peaks per cascade 2
Number of glow peaks between cascades. 1 = cascade at every peak. The ripple cycle is set to breath × N so the next cascade also lands on a peak.
Cascade offset 0.00 s
Nudge the cascade start relative to the glow peak. Negative = earlier, positive = later.
Cascade span 100 %
Percentage of the cycle used to space the three rings. 100% = rings evenly distributed across the whole cycle (default, ring-3 overlaps next cascade's ring-1). 60% = tight cluster at the peak.
